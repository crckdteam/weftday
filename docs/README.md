# Weftday documentation

For people who want to run, check or change Weftday.

If you only want to use it, start with the [guide](https://app.weftday.crckd.live/guide.html), or
[look around with sample data](https://app.weftday.crckd.live/?demo). Neither needs a sign-in.

## Where to start

| You want to | Read |

| Know what Weftday is and what it cannot do yet | [../README.md](../README.md) |
| Run it on your computer, or host your own copy | [self-hosting.md](self-hosting.md) |
| Connect a Google account | [self-hosting.md, step 2](self-hosting.md#2-create-a-google-cloud-client) |
| Check where your data goes before you trust it | [privacy-and-security.md](privacy-and-security.md) |
| Understand the code before changing it | [architecture.md](architecture.md) |
| Send a change | [../CONTRIBUTING.md](../CONTRIBUTING.md) |
